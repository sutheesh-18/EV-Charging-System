# API Reference

Base URL: `http://localhost:8000/api/v1`

Interactive docs (Swagger/OpenAPI) are auto-generated by FastAPI and available once the backend is running:

- Swagger UI: `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- Raw OpenAPI schema: `http://localhost:8000/api/openapi.json`

Import the OpenAPI schema URL or [`postman/VoltGrid.postman_collection.json`](../postman/VoltGrid.postman_collection.json) into Postman for a ready-made request collection.

## Authentication

All endpoints except `/auth/register`, `/auth/login`, `/auth/refresh`, `/health`, and read-only station browsing require a `Bearer` JWT in the `Authorization` header, obtained from `/auth/login`.

| Method | Endpoint | Description |
|---|---|---|
| POST | `/auth/register` | Create a driver / operator / admin account |
| POST | `/auth/login` | Exchange email + password for access & refresh tokens |
| POST | `/auth/refresh` | Exchange a refresh token for a new token pair |

## Users & Vehicles

| Method | Endpoint | Description |
|---|---|---|
| GET | `/users/me` | Current user profile |
| PUT | `/users/me` | Update profile |
| POST | `/users/me/vehicles` | Register a vehicle |
| GET | `/users/me/vehicles` | List my vehicles |
| PUT | `/users/me/vehicles/{id}` | Update a vehicle (e.g. battery %) |
| DELETE | `/users/me/vehicles/{id}` | Remove a vehicle |

## Charging Stations

| Method | Endpoint | Description |
|---|---|---|
| GET | `/stations` | List all stations (optional `?city=`) |
| GET | `/stations/nearby?lat=&lon=&radius_km=` | Stations within radius, sorted by distance |
| GET | `/stations/{id}` | Station detail incl. chargers |
| GET | `/stations/{id}/queue` | Live queue snapshot |
| POST | `/stations` | Create station (operator/admin) |
| POST | `/stations/{id}/chargers` | Add a charger (operator/admin) |
| POST | `/stations/feedback` | Submit a rating/review |
| POST | `/stations/{id}/favorite` | Add station to favorites |
| GET | `/stations/favorites/me` | My favorite stations |

### Example: register + login + get a recommendation

```bash
curl -X POST http://localhost:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"full_name":"Asha","email":"asha@example.com","password":"Passw0rd!","role":"driver"}'

curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"asha@example.com","password":"Passw0rd!"}'
# -> copy access_token from the response

curl -X POST http://localhost:8000/api/v1/recommendations \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"vehicle_id":1,"current_latitude":13.04,"current_longitude":80.23,"max_results":5}'
```
